# 声纹克隆 TTS — Voice Clone Tool

基于 Coqui XTTS v2 的本地语音合成工具，通过上传几秒钟的个人语音样本，即可让模型模仿该声纹朗读任意文字内容。支持中、英、日、韩等 14 种语言，所有计算在本地完成，无需联网。

---

## 功能特性

| 功能 | 说明 |
|------|------|
| 声纹克隆 | 上传 3-10 秒语音样本，模型提取声纹特征用于后续合成 |
| 多语言合成 | 支持中文、英语、日语、韩语、法语、德语等 14 种语言 |
| 语速控制 | 支持 0.5x - 2.0x 倍速调节（librosa time_stretch 不改变音调） |
| 流式预览 | 实时合成并播放，无需等待完整文件生成 |
| 流式逐句播放 | 逐句合成、边合成边播放，首句延迟低至 5-15 秒 |
| 合成结果缓存 | 相同文本/声纹/语速自动缓存，重复请求秒级响应（500MB + 7 天 LRU） |
| 模型预热 | 启动时后台自动预热推理，消除首次请求 10-30 秒模型加载延迟 |
| 声纹管理 | 上传多个声纹，可预览试听、查看创建时间、选择、删除 |
| 本地运行 | 全程离线计算，语音数据不上传云端 |
| 中文界面 | 全中文操作界面，步骤引导、进度指示器，降低使用门槛 |

## 快速开始

### 1. 安装依赖

```bash
# 克隆项目后，进入目录
cd tts-voice-clone-tool

# 创建虚拟环境
python3 -m venv venv
source venv/bin/activate

# 安装依赖
pip install --upgrade pip
pip install -r requirements.txt
```

### 2. 启动服务

```bash
bash run.sh
```

或手动启动：

```bash
source venv/bin/activate
python3 app.py --host 0.0.0.0 --port 8080
```

首次启动会自动下载 XTTS v2 模型（约 2GB），请保持网络畅通。启动后默认执行模型预热（约 10-30 秒），首次合成无需等待模型加载。可通过 `--no-warmup` 跳过预热：

```bash
python3 app.py --no-warmup
```

### 3. 使用流程

```
第一步：上传语音样本
  → 录制一段 3-10 秒的清晰语音（WAV/MP3/M4A 等格式）
  → 拖拽或点击上传

第二步：选择声纹
  → 上传完成后会自动选中该声纹
  → 可点击 ▶ 按钮预览试听
  → 可选择已上传的其他声纹

第三步：输入文字并生成
  → 选择目标语言（中文/英语/日语...）
  → 输入或粘贴要转换的文字
  → 拖动语速滑块调节速度（0.5x - 2.0x）
  → 点击「生成语音」生成完整文件
  → 或点击「流式预览」实时合成播放
  → 或点击「流式逐句播放」逐句合成、边合成边播放
  → 生成后可下载 WAV 文件
```

## 核心技术原理

### XTTS v2 模型

Coqui XTTS v2 是一个基于 Transformer 的多语言语音合成模型，核心原理：

1. **声纹编码器**：将参考音频（几秒钟的人声）编码为固定维度的声纹嵌入向量（speaker embedding），捕捉音色、语调、语速等个性特征

2. **文本编码器**：将输入文本编码为语义表示，支持多语言（共享的文本表示空间）

3. **解码器**：以声纹嵌入为条件，将文本语义表示解码为 Mel 频谱图，再通过声码器（vocoder）转换为波形音频

4. **零样本声纹克隆**：训练时未见过的说话人，只需提供几秒参考音频即可克隆，无需微调

### 文本预处理

为了改善合成质量，引擎对输入文本进行以下预处理：

- **标点规范化**：统一智能引号、破折号、省略号格式
- **长文本分句**：按句子边界（中英文句号、问号、感叹号、分号等）自动分拆为句子，支持中英文混合文本
- **空格整理**：合并多余空格，清理格式噪音

### 合成缓存

为避免重复合成相同的文本，系统实现了基于 MD5 的缓存机制：

- **缓存键**：`MD5(text + voice_id + language + speed)` 生成唯一缓存键
- **存储**：合成的 WAV 文件保存到 `cache/` 目录
- **LRU 淘汰**：按访问时间排序，缓存总大小超过 500MB 时自动删除最旧条目
- **过期清理**：超过 7 天未修改的缓存自动清理，启动时执行

### 语速控制

使用 `librosa.effects.time_stretch` 实现变速不变调：

- **范围**：0.5x - 2.0x（慢速到快速）
- **原理**：时域拉伸/压缩，保持基频不变
- **应用**：合成完成后对波形进行变速处理，不改变声纹音调

### 流式逐句播放

通过 Generator + Binary Stream 实现边合成边播放：

- **后端**：`clone_voice_sentences()` 生成器逐句合成，每句通过 `yield` 立即返回 WAV 二进制块
- **传输**：每个句子前加 4 字节大端长度前缀，前端逐块解析
- **前端**：Web Audio API 的 `decodeAudioData` 逐句解码播放，或使用 `HTMLAudioElement` + Blob URL 播放
- **优势**：首句延迟 5-15 秒，远低于等全文合成完毕的 30-60 秒

### 音频处理链

```
上传文件 (M4A/MP3/FLAC/OGG/WAV)
    │
    ▼
格式校验 → 允许格式 + 大小 < 50MB + 时长 ≥ 1秒
    │
    ▼
格式转换 (自动选用最佳工具)
    pydub → soundfile → afconvert → ffmpeg
    │
    ▼
统一规格: 24kHz / 单声道 / 16-bit WAV
    │
    ▼
存入 voice_profiles/ 目录
```

### CPU 性能优化

针对 Intel CPU 的优化策略：

| 优化项 | 说明 |
|--------|------|
| OMP_NUM_THREADS | 设置 OpenMP 线程数 = CPU 核心数，并行矩阵运算 |
| MKL_NUM_THREADS | 设置 Intel MKL 线程数，加速 PyTorch 的 CPU 推理 |
| NUMEXPR_NUM_THREADS | 设置 NumExpr 线程数，加速数值计算 |
| torch.set_num_threads | PyTorch 内部线程池大小 |
| MKLDNN benchmark | 自动选择最高效的运算内核（如果 PyTorch 版本支持） |
| 模型预热 | 启动时后台线程用已有声纹合成一段短文本，触发模型计算图编译，后续请求无需重新加载 |
| 安全加固 | 所有文件路径路由通过 `_sanitize_filename()` 防范路径遍历攻击

## API 文档

### GET `/api/status`

服务状态和声纹统计。

### GET `/api/voices`

列出所有已上传的声纹信息，包括文件名、大小、创建时间。

### POST `/api/upload`

上传语音样本。支持 WAV/MP3/FLAC/OGG/M4A 格式。

**参数**：`audio`（文件，表单数据）

### POST `/api/synthesize`

文字转语音（文件模式）。返回 WAV 文件的下载 URL。

**请求体**：
```json
{
    "text": "要转换的文字",
    "voice_id": "声纹 ID",
    "language": "zh-cn",
    "speed": 1.0
}
```

**请求验证**：所有合成接口（`/api/synthesize`、`/api/stream`、`/api/stream-chunks`）复用统一验证函数 `_validate_synthesis_request()`，自动校验文本长度（≤5000 字符）、语速范围（0.5-2.0）、语言代码有效性、声纹是否存在。

### POST `/api/stream`

文字转语音（流式模式）。直接返回 WAV 音频流。

**请求体**：
```json
{
    "text": "要转换的文字",
    "voice_id": "声纹 ID",
    "language": "zh-cn",
    "speed": 1.0
}
```

### POST `/api/stream-chunks`

文字转语音（流式逐句播放模式）。返回二进制流，每句前带 4 字节大端长度前缀。

**请求体**：同上（`speed` 可选，默认 1.0）。

**响应格式**：
```
[4字节 大端长度] [WAV 数据] [4字节 大端长度] [WAV 数据] ...
```

错误时长度前缀的最高位（0x80000000）置 1，后续数据为 JSON 错误描述。

### GET `/api/voice-audio/<voice_id>`

获取声纹音频文件，用于前端预览试听。

### DELETE `/api/delete-voice/<voice_id>`

删除指定声纹。

### POST `/api/clear-outputs`

清空所有已生成的输出文件。

## 常见问题

### 合成速度慢

XTTS v2 模型较大（约 1.8GB），CPU 推理需要一定时间。建议：
- 尽量减少单次合成文字量
- 使用 **流式预览**（同时生成同时播放，减少等待感）
- 开启 **模型预热**（默认启动，首次合成无需等待模型加载）
- 通过 `OMP_NUM_THREADS` 等环境变量优化线程利用率

### 端口被占用

中文（简体）、英语、日语、韩语、法语、德语、意大利语、葡萄牙语、西班牙语、俄语、荷兰语、土耳其语、阿拉伯语、印地语。

### 语音样本有什么要求？

- 建议 3-10 秒
- 背景噪音尽量少
- 说话清晰、语速自然
- 与目标合成语言尽量一致（中文样本合成中文效果最佳）

### 端口被占用

默认使用 8080 端口。可通过 `--port` 参数指定：

```bash
python3 app.py --port 9000
```

### 支持哪些语言？

中文（简体）、英语、日语、韩语、法语、德语、意大利语、葡萄牙语、西班牙语、俄语、荷兰语、土耳其语、阿拉伯语、印地语。
